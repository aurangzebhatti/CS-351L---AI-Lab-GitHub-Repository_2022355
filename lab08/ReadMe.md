 Neural Networks with Iris and Wine Datasets

This project demonstrates the use of neural networks for classification on the Iris and Wine datasets.
 Part 1: Iris Dataset
- Build and train a neural network with one hidden layer.
- Modify the model by adding an additional hidden layer.
- Compare the performance (accuracy and loss) of both models.
 Part 2: Wine Dataset
- Preprocess the Wine dataset (standardization and one-hot encoding).
- Train a neural network with two hidden layers.
- Visualize the confusion matrix of test predictions.
 Requirements
- `tensorflow`
- `scikit-learn`
- `matplotlib`
- `seaborn`
- `numpy`

Install dependencies:
```bash
pip install tensorflow scikit-learn matplotlib seaborn numpy
```

## How to Run
1. Clone or download the repository.
2. Open the Jupyter/Colab notebook and run the cells.

## Visualizations
- Training/validation accuracy/loss graphs.
- Confusion matrix for test set predictions.
